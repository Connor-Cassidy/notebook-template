\section{A Simple Definition}
\label{sec:basics}

The symbols $x \in \R$ use a shared macro. The value $\notebookvalue$ uses a
notebook-specific macro.

\begin{definition}[A demonstration]
\label{defn:example}
For this example, define the size of a real number by
\begin{equation}
  s(x) = \abs{x}.
  \label{eq:size}
\end{equation}
\end{definition}
